# 03 — Front-End : Design system et thèmes visuels

## 1. Principes du Design System

L'interface de MAZZ Code applique une esthétique sobre et professionnelle conçue pour les sessions de développement prolongées :
- **Typographie soignée** : Titres et réponses en police avec empattement (serif), code source et identifiants techniques en police monospace (`JetBrains Mono`).
- **Absence totale d'émojis** : L'interface et la documentation respectent la règle zéro émoji (`check-no-emoji.mjs`), remplacés par des icônes vectorielles claires.
- **Micro-interactions douces** : Transitions discrètes (`var(--ease-soft-snap)`), reflets subtils de réflexion (*thinking shimmer*) sans surcharge cognitive.

## 2. Thèmes disponibles

Trois thèmes visuels complets sont supportés, chacun déclinable en mode sombre, clair ou synchronisé avec le système d'exploitation :
1. **Bioforge Leaf** : Palette inspirée de la biologie computationnelle et des interfaces de laboratoire, dominante ardoise et accents vert feuille.
2. **Blueprint Engineer** : Palette technique d'ingénierie, dominante bleu nuit et contrastes techniques.
3. **Claude Desktop** : Palette sobre beige / pierre / anthracite inspirée de l'interface Claude officielle.
